# ATM Simulator

A simple Python-based ATM simulator built as a mini project. It replicates the core functions of a real ATM through a command-line interface.

## Features

- **Deposit Money** – Add funds to your account balance
- **Withdraw Money** – Withdraw funds with balance validation
- **Check Balance** – View current account balance

- **Print Slip** – Generate a transaction receipt/slip after each operation

## How to Run

1. Clone this repository: `git clone https://github.com/samuelthokal720-cmd/atm-simulator.git`
2. Navigate into the folder: `cd atm-simulator`
3. Run the program: `python MiniAtm.py`
